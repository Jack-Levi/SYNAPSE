## ¿Cómo está conectado a GitHub?

Esta carpeta es un repositorio Git. Cada vez que hagas cambios en tus notas de Obsidian, puedes hacer:

```bash
git add .
git commit -m "Actualizar notas de Obsidian"
git push
```
