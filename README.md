# SYNAPSE

Proyecto creado desde cero y vinculado a Obsidian.

## Estructura

- `README.md` — Documentación principal del proyecto.
- `.gitignore` — Archivos y carpetas que Git ignora.
- `obsidian/` — Notas y estructura lista para abrir como vault en Obsidian.

## Cómo empezar

1. Abre Obsidian.
2. Selecciona **Abrir vault como carpeta** (o "Open folder as vault").
3. Apunta a esta carpeta: `SYNAPSE`.
4. Dentro encontrarás la carpeta `obsidian/` con tus notas iniciales.

## Git

Este proyecto está versionado con Git. Para subirlo a tu GitHub:

```bash
git remote add origin https://github.com/Jack-Levi/SYNAPSE.git
git branch -M main
git push -u origin main
```

> Nota: Crea primero el repositorio vacío en https://github.com/Jack-Levi (sin inicializar con README para evitar conflictos).
